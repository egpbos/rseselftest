## Research Software Engineer(ing) (RSE) self-test
This self-test webapp tells you (a researcher) whether you are an RSE or RSEing and gives you some resources to follow up in either case.
It can be run from GitHub Pages, any other static webserver, or straight off your own computer.
Nothing is recorded or sent home.

I used it in a presentation among astronomers to raise awareness of the role of software in almost everyone's job nowadays and, therefore, the importance of recognizing the time and effort that goes into building this.

Feel free to use it, add to it (especially links to resources relevant to your area) and let me know how it went!
